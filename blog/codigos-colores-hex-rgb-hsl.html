Códigos de colores HEX, RGB, HSL y CMYK explicados

18 junio 2026 · 5 min de lectura

El color es un elemento fundamental del diseño, tanto web como gráfico. Pero para trabajar con colores de forma precisa es necesario entender los diferentes sistemas de representación cromática. HEX, RGB, HSL y CMYK son los formatos más utilizados, y cada uno tiene sus aplicaciones específicas. En esta guía te explicamos cómo funcionan y cómo convertir entre ellos.

HEX (Hexadecimal)

El formato HEX es el más utilizado en diseño web. Representa los colores mediante un código de 6 caracteres precedido por el símbolo #, combinando dos dígitos hexadecimales para cada canal: rojo, verde y azul (RRGGBB). Por ejemplo, #22c98a representa el color verde característico de Priquer.

Cada par de dígitos va de 00 (0 en decimal) a FF (255 en decimal), lo que permite representar más de 16 millones de colores. También existe el formato HEX abreviado de 3 caracteres (#RGB) para colores básicos, y HEX con canal alfa de 8 caracteres (#RRGGBBAA) para transparencia.

RGB (Red, Green, Blue)

RGB es el modelo de color aditivo que utilizan las pantallas. Define cada color mediante tres números enteros entre 0 y 255 que representan la intensidad de rojo, verde y azul. Se escribe como rgb(rojo, verde, azul). Por ejemplo, el color verde de Priquer en RGB es rgb(34, 201, 138).

RGB es el formato nativo de monitores, televisores y cualquier dispositivo con pantalla. La mayoría de los lenguajes de programación y librerías gráficas utilizan RGB como formato interno.

HSL (Hue, Saturation, Lightness)

HSL es un modelo de color más intuitivo para los humanos. Define los colores mediante tres parámetros:

  • Hue (matiz): El ángulo en la rueda de colores, de 0 a 360 grados. 0 es rojo, 120 es verde, 240 es azul.
  • Saturation (saturación): La intensidad del color, de 0% (gris) a 100% (color puro).
  • Lightness (luminosidad): La claridad del color, de 0% (negro) a 100% (blanco).

HSL es especialmente útil para crear paletas de colores coherentes porque variar la luminosidad o saturación manteniendo el mismo matiz produce colores armónicos de forma natural.

CMYK (Cyan, Magenta, Yellow, Key/Black)

CMYK es el modelo de color sustractivo utilizado en impresión. A diferencia de los modelos anteriores, que se basan en luz (pantallas), CMYK se basa en pigmentos (tinta). Combina cuatro colores: cian, magenta, amarillo y negro (key).

Cada valor se expresa como un porcentaje de 0% a 100%. Cuanto mayor es el porcentaje, más tinta se aplica. En teoría, la combinación de cian, magenta y amarillo al 100% debería producir negro, pero en la práctica se usa el canal negro independiente porque las tintas reales no son perfectamente puras.

Cuándo usar cada formato

  • HEX: Diseño web, CSS, HTML. Es el estándar para definir colores en código frontend.
  • RGB: Programación gráfica, librerías de imagen, APIs de Canvas. Es el formato universal para procesamiento de imágenes.
  • HSL: Creación de paletas y temas de color. Ideal para generar variaciones armónicas de un color base.
  • CMYK: Diseño para impresión: folletos, tarjetas, carteles, revistas.

Cómo convertir entre formatos

Convertir entre formatos de color manualmente requiere cálculos matemáticos. Por suerte, existen herramientas online que hacen la conversión al instante. Un conversor de colores online te permite introducir un color en cualquier formato y obtener su equivalente en los demás, además de incluir un selector visual para explorar colores.

Conclusión

Entender los diferentes sistemas de representación de colores es fundamental para cualquier persona que trabaje en diseño o desarrollo web. Cada formato tiene sus fortalezas y el mejor enfoque es conocerlos todos y usar el más adecuado para cada situación.
