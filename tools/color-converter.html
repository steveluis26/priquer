Conversor de colores HEX a RGB, HSL y CMYK online gratis

Nuestro conversor de colores online te permite transformar cualquier color entre los formatos más utilizados en diseño y desarrollo web: HEX, RGB, HSL y CMYK. Solo elige un color con el color picker visual o escribe un código hexadecimal, y obtén los valores equivalentes al instante.

Ideal para diseñadores gráficos, desarrolladores web y cualquier persona que trabaje con colores digitales. Todo el procesamiento ocurre en tu navegador — rápido, preciso y privado.

Formatos de color soportados

HEX es el formato más común en HTML y CSS. RGB define colores por sus componentes rojo, verde y azul. HSL usa matiz, saturación y luminosidad, ideal para ajustes intuitivos. CMYK es el estándar para impresión, combinando cian, magenta, amarillo y negro.

¿Para qué usar un conversor de colores?

  • Convertir colores entre formatos para CSS y diseño web
  • Obtener valores CMYK para diseño de impresión
  • Explorar variaciones de color con el color picker visual
  • Copiar rápidamente valores de color para usar en tus proyectos
